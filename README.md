**适用场景**：想做电影质感 AI 短片 / 广告片的创作者。

**怎么用它搞钱**：广告片 / 宣传片定制——品牌方要"电影感"短视频时，这套"真实机位语言"方法论就是差异化报价的理由。

- 什么时候用 / 常见坑：多镜头、多场景同一主角的视频时用；三招缺一不可——只锁参考图不锁描述、或只锁描述不做尾帧续接，都会在某一镜崩掉；帖末互动提问不影响方法完整性。

**适用场景**：做多镜头、多场景同一主角的 AI 视频，被换脸问题困扰的创作者。

**怎么用它搞钱**：人物一致性代制——"定妆图＋固定描述＋尾帧续接＋抽帧验收"是一套可复用的品控流程，接单时可写进交付标准。

### @FireflyGlowAI《AI 视频抽卡最难绷的不是脸，是狼到底多大》

**核心提炼**
- 解决什么问题：双角色同框时相对比例全靠模型猜，"一只很大的狼"这种形容词没有标尺——作者在 EP01《小红帽：同行》制作中改用数字比例锁定。
- 核心用法（3 条）：1) 提前做一张双角色合拍参考板，把比例直接写成数字：小红帽身高 138cm，狼四足站立时肩高大约到她的胸口到肩部，狼抬头时头部接近她的头部高度，两人距离 2–3 米；2) 工作流：剧本和分镜用 ChatGPT，视频用 Seedance 2.5；3) 方法要点：与其写"一只很大的狼"，不如直接写相对高度，等于给了模型一把能对照的尺子。
- 什么时候用 / 常见坑：双角色、多角色同框，相对体型、身高差必须可控时用；注意这是单集案例中提炼的方法，不是独立方法帖，数字比例要按自家角色重写，不能照抄 138cm；参考板要提前做、不要等到生成时才口头描述。

**适用场景**：做双角色、多角色同框 AI 视频，需要锁定相对比例的创作者。

**怎么用它搞钱**：多角色同框代制——"合拍参考板＋数字比例"是一套可复用的开工件，接单时先出参考板再谈成片，返工率更低。

**来源**：[@FireflyGlowAI](https://x.com/FireflyGlowAI/status/2115051457808392395)（2026-10-27）
